Verificación del prototipo HTML
Navegación entre páginas
Las páginas index.html, reportar.html y rescates.html incluyen un menú común que permite desplazarse entre las interfaces del sistema.

Formulario de rescate
El formulario de reportar.html contiene:

Campo para el nombre provisional del animal.
Categorías de perros, gatos y fauna silvestre.
Niveles de urgencia alta, media y baja.
Área de texto para describir el estado del animal.
Campos complementarios de ubicación y contacto.
Estructura semántica
Las páginas utilizan las etiquetas header, nav, main, section, article y footer de acuerdo con la función de cada bloque.

Organización de recursos
El logotipo está almacenado en la carpeta assets/img, separado de los archivos HTML.

Validación del código
Los tres documentos HTML fueron revisados con el Markup Validation Service de la W3C y no presentaron errores de sintaxis.
