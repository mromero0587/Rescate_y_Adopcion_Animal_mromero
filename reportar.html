Orientación para clasificar la urgencia

Urgencia alta

El animal presenta heridas graves, sangrado, dificultad para respirar, inmovilidad o un peligro inmediato.

Urgencia media

El animal necesita atención, pero permanece estable y no se encuentra expuesto a un riesgo inmediato.

Urgencia baja

El animal no muestra lesiones graves, pero requiere protección, seguimiento o búsqueda de un hogar responsable.
